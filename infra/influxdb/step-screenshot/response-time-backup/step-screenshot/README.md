# Ступенчатые ряды со скриншота, 17–18 октября 2026

[Дашборд Grafana](http://localhost:3001/d/screenshot-steps-20261017) содержит
общий график «Сценарий» из четырёх линий и четыре отдельных графика. Он включён в
[InfluxDB Replay](http://localhost:3001/d/influxdb-replay).

[Верхняя оранжевая ступень крупнее](http://localhost:3001/d/screenshot-steps-20261017?from=1792257600000&to=1792265700000&timezone=Europe%2FMoscow&viewPanel=panel-2).

Данные: 17.10.2026 14:23:30 — 18.10.2026 06:52:15, Europe/Moscow;
3956 точек на цвет, 15 824 всего, шаг 15 секунд.

InfluxDB: org `atropos`, bucket `metrics-replay`, measurement
`screenshot_step_replay`, field `value`, tag `trace=orange|green|yellow|blue`.

Ревизия 2 исправляет искажение формы предыдущей реконструкции. Первая
верхняя оранжевая ступень прочитана непосредственно с подробной картинки
пользователя `source/orange-high-plateau-reference.png`. Сохранены восемь
пиков, семь провалов ниже плато, видимая ширина и наклонные участки между
ними. Откаты занимают несколько отсчётов, а не одну точку. Остальная история
и другие цвета оцифрованы с полного исходного скриншота. Значения прежней
тестовой фикстуры не используются.

Единица TPS задана пользователем; переименование не меняет значения.
На обеих картинках нет числовой шкалы Y, поэтому масштаб восстановлен:
ноль = 0, нижнее оранжевое плато = 100 TPS. Подробный оранжевый рисунок приведён к
этой шкале по тихому плато и высоте крупных пиков. Скрытые наложением
нижние участки других цветов приближённые. Это реконструкция по картинкам,
а не восстановленная исходная телеметрия. Красный порог и синяя рамка не
являются рядами данных. Случайный шум не добавляется.

Все графики соединяют точки линейно и читают сырые отсчёты без агрегации.
У отдельных цветных панелей шкала Y автоматически меняется при увеличении.
`upper-plateau-comparison.png` сравнивает ряд с подробной картинкой;
`preview.png` показывает всю историю. SHA256 источников и калибровка
сохранены в `metadata.json`.

`metrics.lp` подхватывается штатным `seed-replays.sh`; одинаковые метки
и времена обновляют существующие точки без дубликатов. В `verification.json`
проверены ширина откатов, совпадение данных в InfluxDB и Grafana и сохранность
всех остальных метрик. Предыдущая ревизия сохранена в staging-резервной копии.

Для повторной генерации нужны Python, numpy, Pillow, matplotlib:

```powershell
python infra/influxdb/step-screenshot/generate.py
```

Генератор использует `build_overview.py` и `dashboards/` из родительской папки
InfluxDB (в staging — из своей папки). Готовый `metrics.lp` не требует Python.

```powershell
docker compose -f infra/docker-compose-monitoring.yml run --rm influxdb-seed
```
