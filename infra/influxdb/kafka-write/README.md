# Время записи в кафку

Дашборд: `http://localhost:3001/d/kafka-write-time-replay`.
Также включён в общий `InfluxDB Replay`.

Диапазон: **15.09.2026 20:00 — 16.09.2026 02:20 (Москва)**.
Measurement `kafka_write_time`, поле `value`, единица **мс**, подтверждена пользователем.
1521 точка с шагом 15 секунд. Шкала графика 220–750 мс, жёлтая линия.

Это приблизительное восстановление по предоставленному скриншоту,
а не исходные измерения Kafka. Жёлтая линия выделена из изображения;
сохранены видимые вершины выбросов и нарастание разброса в конце.
Случайный шум не добавлялся. Фактическая частота исходных измерений неизвестна.
Точность ограничена растром: примерно 19,2 с/пиксель по X и 0,94 мс/пиксель по Y.
Временные метки вершин привязаны к ближайшему 15-секундному отсчёту,
промежутки заполнены линейной интерполяцией.

`reference.png` — исходный скриншот, `reference-knots.csv` — оцифрованные вершины,
`reconstruction-overlay.png` — голубая реконструированная линия поверх источника для проверки.
`metrics.csv` и `metrics.lp` — готовые данные, `calibration.json` — калибровка,
`verification.json` — результаты сверки InfluxDB, Grafana и сохранности предыдущих рядов.

Из корня Atropos:

```powershell
python infra/influxdb/kafka-write/generate.py
python infra/influxdb/build_overview.py
docker compose -f infra/docker-compose-monitoring.yml run --rm influxdb-seed
```

Для новой даты: `generate.py --date YYYY-MM-DD`. Старые точки при этом остаются.
Готовый seed автоматически импортирует `kafka-write/metrics.lp`; повторная запись
тех же временных меток обновляет существующие точки без дубликатов.
Grafana показывает все сырые точки без усреднения.
Поверх исходной линии показано голубое скользящее среднее за 15 минут:
Flux `movingAverage(n: 60)` при шаге 15 секунд. Среднее вычисляется при запросе;
новые точки в InfluxDB не записываются. Первые 59 отсчётов нужны для прогрева окна.
При приближении запрашиваются дополнительные 15 минут предыстории.
`verify_mean.py` сверяет все значения средней линии с арифметическим расчётом
и проверяет сохранность данных; результат — `mean-verification.json`.
`digitize_reference.py` нужен только для повторной оцифровки и требует NumPy/Pillow;
обычная генерация и работа compose не требуют дополнительных пакетов.
