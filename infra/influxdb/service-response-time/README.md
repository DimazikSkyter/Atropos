# Время отклика сервисов, 5 октября 2026

Четыре независимых ряда из предоставленного изображения: 00:00–11:50,
Europe/Moscow, шаг 15 секунд, по 2841 точке; всего 11 364 значения.
Пользователь подтвердил миллисекунды и исключение голубой нижней границы.

| Сервис | Цвет | Начальный средний уровень |
|---|---|---|
| service1 | зелёный | около 40 мс |
| service2 | жёлтый | около 70 мс |
| service3 | оранжевый | около 53 мс |
| service4 | красный | около 40 мс |

Это приблизительное восстановление, не исходная телеметрия. Вертикальная шкала
и легенда обрезаны. Масштаб задан линейным преобразованием: медиана зелёного
и красного раннего участка — 40 мс, медиана жёлтого — 70 мс, согласно заданным
пользователем приблизительным уровням. Точные числовые значения и амплитуды
неизвестны. Временная шкала привязана к шести подписям 00:00–10:00. Небольшой
обрезанный фрагмент слева до полуночи исключён; правый край округлён до 11:50
в пределах половины пикселя. Точность по времени — около 20,85 с/пиксель.

Метод: выделение цветных штрихов, выбор непрерывного пути среди связных
кандидатов для отсечения JPEG-артефактов, сохранение резких вершин огибающей,
линейная интерполяция на сетку 15 секунд. Случайный шум не добавляется.
Перекрывающиеся зелёный и красный участки менее точны; короткие пропуски
интерполируются. Имена service1–service4 условные и не связаны с предыдущим RPS.

InfluxDB: bucket `metrics-replay`, measurement `service_response_time`,
field `value` (float, мс), tag `service`. Старые measurements не изменяются.
`metrics.lp` автоматически подхватывает существующий `seed-replays.sh`;
повторный импорт идентичных measurement/tag/timestamp идемпотентен.

Grafana: `/d/service-response-time-20261005`, источник `influxdb-replay`,
четыре сырых ряда без агрегации; JSON —
`../dashboards/service-response-time-20261005.json`.

Восстановление артефактов: `python generate.py` (Python 3, Windows PowerShell,
сторонние пакеты не требуются). Проверка: `python publish_verify.py draft`.
Фазы `before`, `write`, `after` проверяют отсутствие конфликта, импортируют
новый measurement и сверяют каждое значение через InfluxDB и Grafana.
Параметры подключения можно переопределить переменными окружения из compose.
