значения после 18:19:15, включая рост и пики, сохранены. Фон задан пользователем,
а не считан со скриншота. Генератор применяет его при каждом повторном запуске.

Это реконструкция скриншотов по вручную откалиброванным опорным точкам,
а не восстановление исходных реальных измерений. `reference-full.png` задаёт
шкалу верхнего графика (0–25 ms); нижний график читается из `reference.png`
со шкалой 0–10 s. Числа, точная принадлежность сливающихся трасс и субпиксельное
время приблизительны. Шаг 5 s сохраняет форму; он не означает точность исходника
до 5 s. Случайный шум не добавляется. После 18:25 значения ВО не экстраполируются.

Всего 3 073 точки: 8 × 121 для ВО и 5 × 421 для диспетчера. В Grafana запрашиваются
сырые значения без `aggregateWindow`; скрытая агрегация не сглаживает пики.
`preview.png` показывает оба исходных диапазона и совместный увеличенный участок.

Повторное получение готовых данных использует только стандартную библиотеку Python:

```powershell
python infra/influxdb/sync-dispatcher/digitize_reference.py
python infra/influxdb/sync-dispatcher/generate.py --date 2026-10-05
python infra/influxdb/sync-dispatcher/build_dashboard.py
python infra/influxdb/build_overview.py
docker compose -f infra/docker-compose-monitoring.yml run --rm influxdb-seed
```

`metrics.lp` подхватывается существующим загрузчиком. Повторная запись одинаковых
measurement/host/timestamp обновляет те же точки и не увеличивает их число.
Источник данных и постоянные volumes мониторинга используются прежние.
