# RPS сервисов, 4 октября 2026

Приблизительная оцифровка предоставленного скриншота: 20:27–23:27, Europe/Moscow.
Часовой пояс принят по контексту пользователя; исходная частота измерений неизвестна.
Значения RPS восстановлены по пяти делениям вертикальной шкалы, время — по шести
подписанным получасовым делениям. Шаг восстановленных рядов — 15 секунд.

| Сервис | Цвет |
|---|---|
| service1 | зелёный |
| service2 | жёлтый |
| service3 | голубой |
| service4 | оранжевый |
| service5 | красный |

Зелёная линия видна только с 22:50:15. Предшествующие значения service1 неизвестны
и не добавлены. Короткие перекрытия других цветных линий заполнены линейной
интерполяцией между видимыми участками. Случайный шум не добавляется.
Точность изображения — около 5,2 секунды/пиксель и 2,18 RPS/пиксель.

InfluxDB: bucket `metrics-replay`, measurement `service_rps`, field `value` (float,
запросов/с), tag `service=service1` … `service5`. Отдельное measurement сохраняет
существующие истории. `metrics.lp` подхватывается существующим `seed-replays.sh`
при следующем запуске seed-контейнера; compose менять не требуется. Повторный
импорт того же файла идемпотентен.

Grafana: `/d/service-rps-20261004`, источник `influxdb-replay`, исходные отсчёты без
агрегации. JSON дашборда находится в `../dashboards/service-rps-20261004.json`.

Фиолетовая линия «Сумма RPS», шкала справа: сумма доступных значений сервисов
строго в каждой временной точке (Flux `group(columns: ["_time"]) |> sum()`).
Усреднение и заполнение отсутствующих значений не применяются. До появления
service1 в 22:50:15 этот сервис в сумму не входит; у левого края также
суммируются только существующие отсчёты. Сумма вычисляется при запросе,
дополнительные точки в InfluxDB не записываются.

`python generate.py` повторяет оцифровку и создаёт CSV, line protocol, метаданные,
дашборд и preview.png. Нужны Windows PowerShell и Python 3, сторонние пакеты не
требуются. `python publish_verify.py draft` проверяет артефакты; фазы `before`,
`write`, `after` выполняют проверку отсутствия конфликта, импорт и сверку всех
значений через InfluxDB и Grafana. Параметры подключения можно переопределить
переменными окружения из compose.
