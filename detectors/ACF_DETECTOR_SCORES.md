# ACF на score других детекторов

Отдельный отчет: [artifacts/acf-detector-scores/report.html](artifacts/acf-detector-scores/report.html).
Входы соответствуют трем приложенным скриншотам:

- CUSUM 10/200 и 40/800: оранжевый TPS 17–18 октября, по 3956 исходных точек;
- Correlation: latency 18 октября, 112 точек по каждому из трех исходных рядов;
  относительный score (красный) и CCF-only вариант из пунктира;
- Trend: накопленный score Cassandra-1 1–2 октября, 5761 исходная точка.

В ACF поступают сами непрерывные score, а не исходные метрики и не бинарные
флаги. Начальные заглушки до готовности нижнего детектора исключены. Сохраненные
выходы проверены повторным запуском классов на тех же значениях. Сырые входы
происходят из Influx replay, первоначально восстановленных по изображениям;
экспертных меток инцидентов нет.

Важна фактическая доступность: Correlation с `alignment_tolerance=1` выдает
score с задержкой 15 секунд. Для ACF используется `issued_at`, а не прежняя
точка `timestamp`, к которой относится оценка. Последний pending не становится
нулем. Готовые provisional-оценки растущего окна включены с явным флагом.

После готовности нижнего уровня ACF отдельно собирает фон и текущее окно.
Без готового верхнего результата в CSV остаются пустые значения, на графиках —
разрыв. Нет дополнения синтетической историей и нет интерполяции score.

| Профиль | window | max_lag | reference_window | threshold |
| --- | ---: | ---: | ---: | ---: |
| default | 256 | 32 | 512 | 3.5 |
| short | 40 | 10 | 160 | 3.5 |
| short_reference | 40 | 10 | 40 | 3.5 |
| compact | 16 | 4 | 32 | 2.0 |

`min_change=0.1` во всех профилях. Первые два — существующие настройки ACF,
третий показывает эффект сокращения фона, четвертый — дополнительная проверка
чувствительности для короткой записи. Пороги разных профилей не калибровались
на общую частоту ложных срабатываний. В обоих latency-score слишком мало точек
для готовности default и short; отсутствие готового результата не означает
измеренный ноль. Для относительного latency-score максимум compact около 0.0063.

Верхняя глубина измеряется по выходу нижнего детектора. Его собственное окно,
сглаживание и память уже влияют на этот ряд. Это не независимая оценка времени
последствий в физической системе. Постоянный score=1 при нулевом фоновом ACF
после заполнения локального окна не выделяется. Большие и малые score могут
иметь одинаковую ACF: класс не измеряет их амплитуду.

```powershell
python -m tests.acf_detector_scores_report
python -m unittest tests.test_acf_detector_scores
```

Источники зафиксированы в `tests/fixtures/acf-detector-scores/`, SHA256 и
настройки — в `manifest.json`. Отчет копирует входы в `inputs/`, сохраняет
точечные CSV, сводку JSON/CSV, профили при максимуме, полные графики и увеличения.
Проверки сверяют нижние score, время выдачи, оба прогрева, причинность,
последнюю точку и ACF/пороги/балл/глубину с независимым NumPy-расчетом.

Реализация ACF и других детекторов и прежние отчеты не изменены.
