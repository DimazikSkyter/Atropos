# Детектор смены разброса MadDetector

`apps.detectors.MadDetector` переносит проверенную на времени записи в Kafka
формулу `WindowedMadDetector.MADDetector` и сам ведёт скользящий референс.
Зависимость от прежних контейнеров Metric/Metrics не нужна.

```python
from apps.detectors import MadDetector

detector = MadDetector(window=20, data_max_size=100)

for value in values:
    severity = detector.update(value)
    if detector.ready:
        print(severity, detector.local_mad, detector.reference_mad)

# Независимый прогон ряда: один результат на каждую входную точку.
scores = detector.detect_single_seria(values)
last_score = detector.detect(values)  # score(values) — синоним
```

`values` — последовательность конечных чисел, один экземпляр — один ряд.
`detect_single_seria()`, `detect()` и `score()` не изменяют активный поток.
`reset()` очищает историю и снова запускает прогрев.

| Параметр | Значение по умолчанию | Смысл |
| --- | --- | --- |
| `window` | 20 | Число последних точек для локального MAD, минимум 2 |
| `data_max_size` | 100 | Длина скользящего референса, не меньше `window` |
| `logger_name`, `logger_props` | Как у `Detector` | Настройка логгера |

При шаге 15 секунд это окна по 5 и 25 минут. Референс включает локальное окно
и текущую точку. На каждом новом отсчёте старейшая точка уходит из референса.
После установления нового режима референс адаптируется и оценка затухает.
Это реакция на изменение разброса, а не постоянно высокий сигнал для любого
шумного участка. Изменение уровня тоже может временно изменить MAD смешанного окна.

## Формула и результат

```text
MAD(x) = mean(abs(x - mean(x)))
local = MAD(последние window точек)
reference = MAD(последние data_max_size точек)
relative = abs(local - reference) / reference
severity = tanh(relative / 2)
```

`tanh(relative / 2)` математически равен исходной нормировке
`2 / (1 + exp(-relative)) - 1`, но точнее вычисляется при малых отличиях.
Это **среднее абсолютное отклонение от среднего**, а не медианное MAD и не
сама дисперсия. Результат 0–1 — оценка выраженности изменения, не вероятность.
Рост и уменьшение разброса учитываются симметрично. Порог классификации и
принудительное насыщение до единицы не добавлены.

До заполнения референса `update()` возвращает 0, `ready` — False,
а `local_mad` и `reference_mad` — None. По умолчанию первые 99 результатов —
прогрев; сотая точка уже оценивается. Нет использования будущих значений.
Для постоянного референса MAD=0 и оценка равна 0.
При `window == data_max_size` оба отклонения совпадают и оценка всегда 0.
Память ограничена `data_max_size`, стоимость шага линейна по размеру референса.

## Отличия от старого тестового запуска

В старом тесте `data_max_size` класса сам не ограничивал данные: тестовый цикл
передавал в `detect()` фрагменты через `Metrics.sub_range_metrics()`.
Из-за ошибки правой границы заявленные 100 точек превращались в 99,
а последняя точка ряда терялась. Здесь `data_max_size` действительно задаёт
размер референса, обрабатывается ровно столько точек и ни одна точка не теряется.
Для сравнения после прогрева можно задать `data_max_size=99`.

Первый фрагмент старого теста также использовал будущие значения для оценки
ранних точек. Новый пакетный прогон повторяет потоковый `update()` и сохраняет
прошлые оценки при дописывании будущих значений.

Модуль не меняет данные, не обращается к БД и не выполняет сглаживание.
Минутное усреднение в Grafana остаётся отдельным способом отображения.

## Повторный прогон после удаления цикла

В конец того же отчета добавлен эксперимент `#without-cycle`: из каждого ряда
вычитается фиксированный прогноз здорового уровня и цикла, затем остаток
подается в существующий MadDetector с прежними окнами 20/100.

Модель каждого сервиса обучена **только первым 720 точкам**, 00:00–02:59:45 МСК.
Этот участок принимается за регулярный. FFT и синусоидальная регрессия
номинируют период; регрессия с шестью гармониками и нижними 90% квадратов
остатков уточняет дробный период в пределах ±2 отсчетов. После этого медианы
64 фазовых групп формируют шаблон, между ними используется круговая линейная
интерполяция. Оценка периода остается дробной, чтобы не накапливать ошибку
округления при прогнозе на последующие часы.

После 03:00 модель фиксирована: ни форма шаблона, ни период, ни здоровый
уровень не обучаются на последующих изменениях. Остатки на обучающем участке
показываются только для диагностики; MAD получает лишь последующие точки.
Сдвиги уровня, рост амплитуды и смена формы/периода поэтому остаются в остатке.

Исходный ряд и остаток оценивают два новых независимых экземпляра MAD,
стартующих одновременно в 03:00. У обоих первый готовый результат на индексе
819, **03:24:45 МСК**. Сравнение ранних средних сделано на независимом
от обучения участке 03:24:45–05:00, поэтому его значения отличаются от
первоначальной таблицы с интервалом 00–05.

| Сервис | Период, минут | Средний ранний score: до → после | Max score на общем интервале: до → после |
|---|---:|---:|---:|
| service1 | 22.953 | 0.280 → 0.182 | 0.566 → 0.737 |
| service2 | 22.955 | 0.310 → 0.204 | 0.459 → 0.763 |
| service3 | 22.953 | 0.301 → 0.152 | 0.460 → 0.730 |
| service4 | 22.819 | 0.291 → 0.180 | 0.457 → 0.451 |

На том же независимом раннем участке стандартное отклонение снизилось:
service1 1.342→0.377 мс; service2 1.407→0.627; service3 1.198→0.206;
service4 1.230→0.530. Это показывает удаление значительной части обычной
цикличности на данных, не использованных при подгонке.

Результат частичный. Ранний средний score уменьшился, некоторые переходы
service1–service3 стали заметнее. У service1 на раннем участке при этом
остается отдельный пик около 0.649. После 10:00 средние баллы остатков
по-прежнему около 0.26–0.30: предобработка не меняет деление двух скользящих
MAD и принятие нового масштаба разброса за текущий фон.

Замороженный шаблон удаляет приближенно исходную цикличность. Если форма,
период или фаза меняются, это остается в остатке вместе со сдвигами уровня
и шумом; отделение этих эффектов требует дополнительного анализа. Для снимка
нет независимой разметки, которая позволяла бы назвать все пики аномалиями.

В отчете сохранены первоначальные результаты MAD. Новые графики содержат
исходный ряд и прогноз цикла, остаток, две линии score на общем интервале,
локальный и референсный MAD остатка. CSV экспортирует все значения,
фазы обучения/прогрева, остатки и оба прогона. Модель и фазовый шаблон
