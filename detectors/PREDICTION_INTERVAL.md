# PredictionIntervalDetector

`PredictionIntervalDetector(Detector)` заменяет заготовку `BondDetector`.
Старое имя оставлено алиасом для совместимости импортов.
Детектор выдаёт **предиктивный интервал следующего наблюдения** по предыдущему
окну и балл отклонения с ослаблением при стабильных границах. Текущая точка
попадает в историю только после оценки.

```python
from apps.detectors import PredictionIntervalDetector

detector = PredictionIntervalDetector(
    window=30, confidence=0.95, scale=1.0, auto_scale=True,
    adaptation_rate=0.05, max_scale=100.0,
    stability_threshold=0.3, stable_score_factor=0.1,
)
detector.fit(training_values)  # необязательно: история + калибровка масштаба
forecast = detector.predict()  # (infimum, supremum) для следующей точки
result = detector.update(next_value)
if result.ready:
    print(result.infimum, result.supremum, result.score, result.raw_score)

# По одному неизменяемому результату для каждой точки, включая прогрев.
results = detector.predict_intervals(values)
```

До получения `window` предыдущих наблюдений возвращается `ready=False`,
`infimum=None`, `supremum=None`, `score=0`. Первая оцениваемая точка имеет
индекс `window`. После `fit()` следующее наблюдение оценивается сразу.
`detector.ready` означает готовность следующего прогноза, `result.ready` —
наличие прогноза для уже переданной точки. `predict()` не меняет состояние.

## Интервал и балл

Для `n=window`, среднего `mu` и **выборочного** стандартного отклонения `s`
предыдущих `n` значений:

```text
alpha = 1 - confidence
h0 = max(noise_floor, ulp(mu), t_(1-alpha/2, n-1) * s * sqrt(1+1/n))
h = scale * h0
infimum = mu - h
supremum = mu + h
```

Множитель `sqrt(1+1/n)` учитывает разброс будущей точки и оценку среднего.
Это интервал для наблюдения, а не более узкий доверительный интервал среднего.
Формула: [NIST](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/predlimi.htm),
квантиль: [SciPy Student t](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.t.html).
SciPy уже присутствует в зависимостях проекта.

Внутри `[infimum, supremum]`, включая границы, `raw_score=score=0`. Снаружи:

```text
d = расстояние до ближайшей границы
raw_score = d / (h+d) = 1 - 1/(1+d/h)
```

При удалении на одну полуширину от границы исходный балл равен 0.5, на две — 2/3.
`raw_score` симметричен, монотонен по расстоянию и принадлежит `[0, 1)`.
При машинном округлении сверху используется `nextafter(1,0)`, снизу для
промаха — `nextafter(0,1)`. Балл не является вероятностью аномалии.
`noise_floor=1e-9` задаёт минимальную базовую полуширину в единицах метрики;
`ulp(mu)` сохраняет различимые границы на очень больших уровнях.

## Ослабление при стабильном окне

Для текущего значения сравниваются две пары границ: прогноз по предыдущим
`window` точкам и интервал окна после добавления наблюдённой точки с удалением
самой старой. Обе пары используют **один текущий `scale`**, поэтому изменение
коэффициента авторегуляцией само по себе не усиливает сигнал.
Прогнозные `infimum`/`supremum`, по которым вычислен `raw_score`, остаются
построенными без текущей точки. Будущие наблюдения не используются.

```text
change = min(1, max(abs(inf_next-inf), abs(sup_next-sup)) / max(h, h_next))
score_factor = stable_score_factor, если change <= stability_threshold, иначе 1
score = raw_score * score_factor
```

`h` и `h_next` — полуширины. Изменение учитывает и сдвиг центра, и изменение
ширины, нормируется на разброс, а не на абсолютный уровень метрики.
По умолчанию `stability_threshold=0.3`, `stable_score_factor=0.1`:
если границы сдвигаются не более чем на 30% большей полуширины, балл уменьшается
в 10 раз. При заметном изменении окна балл сохраняется. Для отключения
ослабления задайте `stable_score_factor=1`; коэффициент должен быть в `(0,1]`,
порог — в `[0,1)`. Дополнительный прогрев не требуется.

В результате доступны `raw_score`, `interval_change` (0…1) и `score_factor`.
Ослабление не обнуляет промахи и не меняет покрытие, `fit()` или авторегуляцию:
они используют реальные попадания в прогнозные границы. При поднормальных
числах положительный балл сохраняется через `nextafter(0,1)`.
Монотонность по расстоянию относится к `raw_score`; итоговая оценка учитывает
ещё и изменение окна. Это инженерное правило подавления фона, не вероятность.

## Масштаб и обучение

- `scale>0` умножает полуширину вокруг среднего. Это также нижняя граница
  автоматического/обученного коэффициента. Значения меньше 1 разрешены.
- `fit(reference, calibrate=True)` строит прогноз для каждой обучающей точки
  после прогрева только по её прошлому окну. Берётся квантиль уровня
  `confidence` величин `abs(x-mu)/h0` методом ближайшего ранга
  `ceil(confidence*m)`. Коэффициент ограничивается `[scale, max_scale]`.
  Это эмпирическая калибровка. При ровно `window` точках ошибок для неё нет.
- `fit(reference, calibrate=False)` только задаёт последнее окно истории.
- `auto_scale=True` после оценки текущей точки выполняет
  `scale_next = clip(scale*exp(adaptation_rate*(miss-alpha)), scale_initial, max_scale)`.
  Промах расширяет **следующий** интервал, попадания постепенно сужают его.
  При частоте промахов `alpha` среднее изменение логарифма равно нулю
  вдали от ограничений; это правило обратной связи, не гарантия покрытия.
- `result.scale` относится к возвращённым границам, `detector.scale` —
  к следующему прогнозу. `fitted_scale` хранит коэффициент после обучения.
- `reset()` восстанавливает только явную обучающую историю и её коэффициент.
  Повторный `fit()` полностью заменяет их. Ошибки валидации состояния не меняют.

Методы `predict_intervals`, `detect_single_seria`, `analyze`, `detect`, `score`
воспроизводят отдельный поток от настроек и явного `fit()`, не меняя активный
поток. `analyze` возвращает последний результат; `detect/score` — его балл;
`detect_single_seria` — только баллы для совместимости с другими детекторами.
Для живой последовательности следует вызывать `update()`.

## Границы применимости

Номинальный уровень точен для независимых одинаково распределённых нормальных
наблюдений при `scale=1`, если минимальная ширина не активна. Скользящие интервалы
не дают одновременной гарантии на весь ряд. На трендах, тяжёлых хвостах,
автокорреляции и циклах требуется оценивать фактическое покрытие на будущих данных.
Авторегуляция и калибровка не устраняют эти предпосылки теоретически.

Каждая оценённая точка, включая аномальную, входит в последующее окно.
Поэтому длительное плато становится новой нормой через `window` наблюдений,
выброс временно расширяет будущие интервалы, а смена периодичности может
не дать промаха. Этот детектор оценивает неожиданность значения, не длительность
инцидента, не ACF и не накопленную инерцию CUSUM.

Ослабление может уменьшать и баллы настоящих слабых аномалий, если они почти
не меняют окно. Для анализа доступны исходный балл и величина изменения;
порог стабильности следует проверять на нужных рядах.

Память потока O(window), обновление O(window); `fit` требует O(m*window + m log m)
времени и O(m) памяти на обучающий ряд длины m. Непредставимые конечные границы
приводят к `ValueError`; бесконечности в результатах не подставляются.
