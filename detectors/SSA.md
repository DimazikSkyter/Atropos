# SSADetector: отклонение от скользящей модели временного ряда

`apps.detectors.SSADetector` оборачивает SSA-оценку из эксперимента в потоковый
детектор с результатом **[0,1]**. `update()` возвращает число; `result` содержит
несжатую оценку и диагностику. CUSUM для этой оценки не нужен.

```python
from apps.detectors import SSADetector

detector = SSADetector(window=192, data_max_size=960)
for value in values:
    score = detector.update(value)
    if detector.ready:
        print(score, detector.result.deformation, detector.result.reference_sigma)

scores = detector.detect_single_seria(values)  # независимый причинный прогон
last_score = detector.detect(values)          # score(values) — синоним
diagnostics = detector.analyze(values)
detector.reset()

# Постоянная исходная норма, как в исследовательском эксперименте:
frozen = SSADetector(window=192, data_max_size=960, refit_interval=None)
```

Один экземпляр обслуживает один равномерно дискретизированный ряд конечных чисел.
Пакетные вызовы не меняют активный поток. До заполнения истории возвращается 0,
`ready=False`. По умолчанию первые 959 оценок — прогрев, 960-я уже рассчитана.

## Окна и нормировка

История `data_max_size` делится на **непересекающиеся** части:

```text
[ референс: data_max_size − window ][ текущее окно: window ]
```

1. По референсу вычисляются среднее, стандартное отклонение σ и Hankel-матрица
   лаговых векторов. Ведущие направления SVD задают здоровое для этого окна
   подпространство. Используется эквивалентное симметричное разложение `eigh`.
2. Из каждого лагового вектора текущего окна вычитается среднее референса.
   Считается часть вектора, ортогональная SSA-подпространству.
3. Среднеквадратичный остаток по всем элементам этих векторов нормируется на σ
   референса. Получается исходная оценка `D = residual_rms / reference_sigma`.
4. Внешняя оценка: **`score = D / (D + score_scale)`**, по умолчанию
   `score_scale=1`. При D=0 → 0; D=1 → 0.5; D=3 → 0.75; D=9 → 0.9.

Это плавное монотонное сжатие, а не вероятность или правило тревоги. Минимумы
и максимумы оцениваемого текущего окна не задают границы шкалы. Большое окно
задает модель и единицу измерения; `score_scale` регулирует сжатие и не меняет
саму SSA-оценку. При D=score_scale оценка всегда 0.5.

Референс обновляется раз в `refit_interval` точек. Между обновлениями все оценки
используют предыдущую модель и ее σ. `reference_end` всегда строго раньше
начала оцениваемого текущего окна; текущая аномалия не увеличивает свою же σ
в момент расчета. После перехода текущие данные постепенно попадают в референс:
устойчивый новый режим становится новой нормой. На заполнении всего большого
окна новым режимом старая норма уже не влияет на модель, с задержкой до
`refit_interval−1` точек. Оценка возвращается к фону нового режима.

В эксперименте был постоянный здоровый референс. По умолчанию здесь он скользит, поэтому
длительное отличие от первоначальной нормы не обязано сохранять высокий score.
`refit_interval=None` фиксирует первую модель и ее σ: устойчивое отклонение
от первоначальной нормы продолжает учитываться. Большой буфер при этом также
ограничен по размеру, новые значения используются только в текущем окне.
Стационарный шум не идеально описывается низкоранговой моделью: его фоновый
score может быть ненулевым. Класс оценивает величину реконструкционного остатка,
не статистическую значимость изменения.

## Параметры

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| `window` | 192 | Текущее окно; минимум 8 |
| `data_max_size` | 960 | Полная история; не меньше `3*window` |
| `lag` | `None` | Длина вектора SSA; вручную 2..`window//2` |
| `energy` | 0.95 | Доля энергии референса для выбора ранга |
| `max_rank` | 12 | Верхний предел ранга; фактически не больше `lag−1` |
| `refit_interval` | 16 | Период обновления; `None` фиксирует первую модель |
| `score_scale` | 1.0 | Значение исходного D, соответствующее score=0.5 |

При шаге 15 секунд это текущее окно **48 минут**, референс **3 часа 12 минут**,
полная история/прогрев **4 часа**, обновление модели раз в **4 минуты**.
Такие значения позволяют включить около двух исходных циклов последнего
графика в текущее окно. Их можно менять под физический масштаб задачи.

При `lag=None` по одному референсу ищется первый пик ACF выше 0.5 в диапазоне
8..`min(128, window//2)`. Если пика нет, используется `min(32, window//2)`.
В текущем окне период не оценивается. При постоянном референсе ранг равен 0:
равный ему постоянный ряд дает 0; любое ненулевое отклонение при σ=0 дает 1.
Непредставимые исходные диагностические величины ограничиваются максимальным
конечным float; ограниченный score вычисляется без переполнения.

Постоянное состояние: O(`data_max_size + lag * rank`); временная память при
переобучении: O(`reference_window * lag + lag²`). Расчет текущей точки:
O(`window * lag * rank`), переобучение: O(`reference_window * lag² + lag³`).
Переобучение амортизируется через `refit_interval`.

## Диагностика и проверка

`SSAResult` неизменяемый: `ready`, `score`, `deformation`, `residual_rms`,
`reference_sigma`, `reference_deformation`, `lag`, `rank`, `reference_size`,
`reference_end`, `refit_age`, `zero_reference_variance`. `reference_deformation`
показывает собственный реконструкционный фон модели и не вычитается из D.

SSA не измеряет каждую смену формы: новые коэффициенты или фазы внутри того
же пространства гармоник могут остаться незаметными после перехода. Уровень,
шум и новая динамика могут увеличивать остаток; тип изменения класс не выводит.

```powershell
python -m unittest tests.test_ssa
python -m tests.visualize_ssa
```

Тесты проверяют независимый SVD-оракул, причинность, непересечение окон,
нормировку, адаптацию новой нормы, границы прогрева, экстремальные конечные
значения, инвариантность к единицам и сохранность активного потока.
Отчет: `artifacts/ssa/report.html`, там же CSV для четырех исходных сервисов
и синтетических проверок. Использован тот же снимок Influx replay, что в MAD;
это ранее реконструированные по изображению ряды, без экспертных меток событий.
